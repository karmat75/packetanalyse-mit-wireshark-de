# Quizzes

Dieser Ordner enthält maschinenlesbare Quizfragen für den Kurs.

## Struktur

```text
quizzes/
├── questions/
│   ├── foundation.yml
│   └── basic.yml
├── exams/
│   └── .gitkeep
└── competencies/
    └── .gitkeep
```

## Grundsatz

Die Fragen sind eigene Kursfragen.

Sie sind keine offiziellen Prüfungsfragen, keine nachgestellten Prüfungsfragen und keine Exam Dumps.

## Lokale Nutzung

Das lokale Tool `packetlab` kann Fragen ausführen, Selbsttests starten und Fortschritt lokal speichern.
